\begin{abstract}
We determine the exact minimum sizes of constrained covering arrays for the
public \texttt{INDUSTRIAL\_8} benchmark at strengths $t=2,\ldots,6$.
If $N_t$ is the minimum number of valid configurations covering every feasible
$t$-way interaction, then
\[
(N_2,N_3,N_4,N_5,N_6)=(18,45,72,144,144).
\]
For strength three, the pinned 2023 CT-Competition table records 54 tests as
the smallest valid entry for this benchmark; a 49-row entry is marked invalid.
The released 45-row array therefore improves that frozen valid comparison by
nine rows, or $16.7\%$, and a matching lower bound proves optimality.
The final release is checked by two independently implemented exhaustive
replays. A pinned Lean 4/Mathlib development additionally kernel-checks the
nontrivial four-row pairwise obstruction, an explicit five-row witness, and the
arithmetic aggregation of class-local lower bounds across nine mandatory
classes. The Lean layer is auxiliary: the complete benchmark parser,
mandatory-class decomposition, and witness-coverage theorem remain checked by
the independent exact replay implementations rather than being claimed as a
full Lean formalization.
\end{abstract}

\section{Introduction}
Combinatorial interaction testing seeks small test suites that cover every
feasible interaction among selected input parameters. In the constrained
setting only tuples that extend to a valid full configuration need be covered.
The \texttt{INDUSTRIAL\_8} instance is a public benchmark from the 2023
Combinatorial Testing Competition. The benchmark family is described by
Bombarda and Gargantini~\cite{bombarda2024}; the competition publishes the
result table used here as a frozen comparison point~\cite{ctcompetition2023}.

The contribution is an exact solution of this one finite model at strengths
two through six. The proof has two parts. First, the constraints decompose the
valid set into nine disjoint mandatory classes with four freely varying Boolean
coordinates, plus 15 residual configurations. This yields class-local lower
bounds. Second, explicit witness suites attain those bounds. Because the model
has only $2^{13}\cdot3=24{,}576$ raw assignments, the full statement can also
be replayed by exact finite enumeration.

The comparison claim is deliberately narrow: the frozen 2023 table has valid
strength-three sizes $55,68,68,54$ and invalid sizes $71,49$. Thus 54 is the
smallest valid entry in that pinned table. We do not claim the table exhausts
later private, unpublished, differently normalized, or independently produced
constructions.

\section{Frozen model and feasible interactions}
The exact benchmark bytes are committed as \texttt{INDUSTRIAL\_8.txt}. They
are byte-for-byte identical to Git blob
\texttt{4ede6ee93f6eea06927f972cf5ba22621ecc3013} at commit
\texttt{7ed44c18a771b9bbdc444a3c9178a7a68510a53f} of
\texttt{fmselab/CIT\_Benchmark\_Generator}. The SHA-256 digest is
\texttt{01785c43dbce4381d928c064c14dfe3c3734237db8fa7c2e84d8647f8ed299b4}.

There are Boolean parameters $p_1,\ldots,p_{13}$ and a three-valued parameter
$p_{14}\in\{v1,v2,v3\}$. A feasible $t$-way interaction is a choice of $t$
distinct parameters together with values that occur in at least one valid full
configuration. A test suite covers the interaction if one of its rows agrees
with all selected parameter-value pairs.

\begin{proposition}[Structure of the valid set]\label{prop:structure}
The model has exactly 159 valid configurations. They decompose into eight
16-row classes indexed by a unique false parameter among
$p_5,\ldots,p_{12}$, one 16-row class with $p_{13}=\mathrm{false}$, and 15
residual configurations with $p_5,\ldots,p_{13}$ all true and
$(p_1,p_2,p_3,p_4)$ not all true. In each of the first nine classes,
$p_1,p_2,p_3,p_4$ range freely over $\{0,1\}^4$.
\end{proposition}

\begin{proof}
The pairwise disjunction constraints on $p_5,\ldots,p_{12}$ imply at most one
of these eight variables may be false. The constraints involving $p_{13}$
imply that if $p_{13}$ is false then all eight are true. The constraints on
$p_{14}$ forbid $v3$ and uniquely determine $v1$ versus $v2$ from $p_3$.
Finally, the last constraint forbids the assignment with $p_1,\ldots,p_{13}$
all true. Hence the valid count is $8\cdot16+16+15=159$.
\end{proof}

Call the first nine classes \emph{mandatory classes}. They are pairwise
disjoint. If $q$ is the false parameter defining one class, then any
interaction containing $q=\mathrm{false}$ can only be covered by a row from
that class.

\section{Class-local lower bounds}
\begin{lemma}[One-way local minimum]\label{lem:one}
At least two rows are required in each mandatory class for global strength two.
\end{lemma}
\begin{proof}
For any free coordinate $p_i$, both values occur with the fixed condition
$q=\mathrm{false}$. A single row cannot realize both.
\end{proof}

\begin{lemma}[Pairwise local minimum]\label{lem:pair}
The minimum number of four-bit words covering every binary pair on every pair
of coordinates is five.
\end{lemma}
\begin{proof}
Four rows are impossible. If four rows covered every pair, then every pair of
columns would contain $00,01,10,11$ exactly once. After row permutation and
column complementation normalize two columns to $0011$ and $0101$. Up to
complement, the only third balanced column orthogonal to both is $0110$, and
there is no fourth balanced column orthogonal to all three. Five rows suffice,
for example
\[
B=\{0000,0111,1011,1101,1110\}.
\]
\end{proof}

\begin{lemma}[Three-way local minimum]\label{lem:three}
At least eight rows are required in each mandatory class for global strength four.
\end{lemma}
\begin{proof}
Fix any three free coordinates. All $2^3=8$ assignments are feasible and each
selected row realizes only one.
\end{proof}

\begin{lemma}[Four-way local minimum]\label{lem:four}
At least sixteen rows are required in each mandatory class for global strength
five, and the same bound holds for strength six.
\end{lemma}
\begin{proof}
At strength five, combine $q=\mathrm{false}$ with all four free coordinates;
all $2^4=16$ assignments are feasible. At strength six, append any remaining
parameter forced true in that class; the same sixteen assignments remain
necessary.
\end{proof}

\begin{theorem}[Global lower bounds]\label{thm:lower}
\[
N_2\ge18,\qquad N_3\ge45,\qquad N_4\ge72,\qquad
N_5\ge144,\qquad N_6\ge144.
\]
\end{theorem}
\begin{proof}
The nine mandatory classes are disjoint, and interactions containing a
class-defining false parameter can only be covered within that class. Multiply
the class-local bounds $2,5,8,16,16$ by nine.
\end{proof}

\section{Constructions and exact optima}
All witnesses use mandatory-class rows. At strength two use complementary
pairs, with cut types cycled across the classes. At strength three use the
five-word array $B$ above, translated by $0000,0001,0010,0011$ and cycled
through the nine classes. At strength four alternate the even- and odd-parity
eight-word subsets of $\{0,1\}^4$. At strengths five and six use all sixteen
four-bit words in every mandatory class.

\begin{theorem}[Exact optima]\label{thm:main}
For the frozen \texttt{INDUSTRIAL\_8} model,
\[
(N_2,N_3,N_4,N_5,N_6)=(18,45,72,144,144).
\]
\end{theorem}
\begin{proof}
Theorem~\ref{thm:lower} supplies the lower bounds. The published witnesses
have exactly those sizes. Both complete replay implementations independently
enumerate all feasible interactions and verify full coverage.
\end{proof}

\section{Verification and reproducibility}
The complete frozen-model theorem is replayed in two independent executable
paths. The Python verifier checks source hashes, enumerates all raw assignments,
derives the 159 valid rows and mandatory classes, solves the local covering
subproblems, reads every witness CSV, enumerates all feasible interactions, and
checks coverage. The C++20 verifier separately parses and evaluates the model
text, independently enumerates configurations/interactions, reads the witness
files, and brute-forces the local minima.

A third, deliberately scoped assurance layer is provided by Lean 4 and Mathlib.
The pinned module \texttt{R003/LocalCovering.lean} proves:
\begin{itemize}
\item \texttt{pairwiseFourRowObstruction}: no four distinct four-bit rows cover
all binary pairs;
\item \texttt{pairwiseFiveRowWitness}: the explicit five-row array covers all
binary pairs;
\item \texttt{nineClassSumLower}: a class-local bound $m$ aggregates to at
least $9m$ across nine classes, with arithmetic specializations for
$18,45,72,144$.
\end{itemize}

Lean is pinned to \texttt{v4.32.0}; Mathlib is pinned to commit
\texttt{81a5d257c8e410db227a6665ed08f64fea08e997}. CI scans production Lean sources
for proof shortcuts, runs an axiom audit with \texttt{--trust=0}, and performs
a fresh \texttt{leanchecker} replay. The formalization has no production
\texttt{sorry} or \texttt{admit}.

The Lean scope is intentionally narrower than Theorem~\ref{thm:main}. It does
not formalize the full benchmark-text parser semantics, the correspondence of
the pinned text file with a Lean model, Proposition~\ref{prop:structure}, or
complete CSV witness coverage. Those obligations are supplied by the two
independent exact full-model replays and the human proof. Accordingly the
release may be described as having an \emph{auxiliary Lean-checked lower-bound
core}, but not as a complete Lean formalization of R003.

The public replay commands are documented in \texttt{VERIFICATION.md};
\texttt{formalization.yaml} records the machine-readable formalization scope.
Search traces, optimizers, and language-model generation are outside the final
correctness oracle.
